# 财务诊断、估值与交易结构

## 一、三表六组勾稽

报表自洽是最低要求。六组里任一组断裂，都要在风险登记表里单列，并直接下调财务质量分。

### 第 1 组：净利润与经营现金流

```
差额 = 净利润 - 经营活动现金流净额
理论差额 ≈ 应收增加 + 存货增加 - 应付增加 - 折旧摊销 - 非付现减值
```

连续两期净利润为正、经营现金流为负，且差额不能用应收存货扩张解释，收入真实性存疑。差额占比（差额/净利润）超过 50% 需要企业逐项说明。

### 第 2 组：应收账款与收入

```
应收增速 - 收入增速 > 15 个百分点 → 预警
DSO = 应收账款 / 营业收入 × 365
```

DSO 显著高于合同账期（超过 30 天），说明回款管理失效或存在放宽信用换收入。叠加应收账龄结构中 1 年以上占比上升，则坏账计提是否充分需要复核。

### 第 3 组：存货与成本

```
DIO = 存货 / 营业成本 × 365
```

DIO 连续上升且收入增速放缓，指向滞销或备货失误。还要看存货结构：原材料、在产品、库存商品的比例变化，库存商品占比上升是最直接的滞销信号。

### 第 4 组：应付账款与采购

```
应付周转天数 = 应付账款 / 营业成本 × 365
```

应付天数突然拉长，可能是占用供应商资金（现金流改善但关系恶化），也可能是无力支付（资金链紧张）。要结合供应商集中度和是否有逾期记录判断。

### 第 5 组：货币资金与利息收入

```
隐含利率 = 利息收入 / 平均货币资金
```

隐含利率显著低于同期活期存款利率，说明资金被质押、冻结或存在受限用途，也可能是货币资金虚增。差额超过 1 个百分点就要问。

### 第 6 组：收入与外部凭证

收入 vs 增值税申报销售额、收入 vs 社保人数对应的人力成本承载力、收入 vs 用电量或物流量（制造业）。三组外部凭证里至少要有一组能对上。

### 收入质量评分

按五个维度打分（各 20 分，合计 100）：现金含量（经营现金流/净利润）、应收质量（DSO 与账龄）、客户分散度（CR5 反向）、可持续性（经常性收入占比）、外部可验证性（第 6 组能否对上）。

## 二、资金消耗与安全运营月数

```
月均净消耗 = 近 3 个月 (期初现金 - 期末现金 + 期间融资流入) 的算术平均
runway(月) = 期末现金及等价物 / 月均净消耗
本轮后 runway(月) = (期末现金 + 本轮净募资) / 月均净消耗
```

判据：<6 个月为紧急（可能被迫低价融资或缩表）；6-12 个月为需立即启动下一轮；12-18 个月为正常；>24 个月为充裕，但要复核资金使用效率是否偏低。

注意剔除一次性因素：设备预付款、大额保证金、政府补助到账，这些会让单月数字失真。用 3 个月平均而不是单月，用经营口径而不是含投资活动。

同时算一个"零融资生存能力"：假设收入按当前增速、费用按计划扩张，现有现金能否撑到经营性现金流转正。多数早期项目答案是否定的，这个结论要写出来，它决定了项目对下一轮融资的依赖程度，也就是对赌条款的实际威慑力。

## 三、敏感性测试

### 三情景法

设三个情景，参数联动，不要只动收入一个变量。

| 情景 | 收入假设 | 毛利率 | 费用率 | 说明 |
|---|---|---|---|---|
| 悲观 | 基准 -15% | 基准 -3pct | 基准 +3pct | 大客户流失或价格战 |
| 基准 | BP 预测 | BP 预测 | BP 预测 | 按企业规划 |
| 乐观 | 基准 +15% | 基准 +2pct | 基准 -2pct | 新品放量超预期 |

每个情景输出：收入、毛利率、净利润、经营性现金流、需追加融资额、按目标倍数测算的估值、投资人 MOIC。表格形式呈现，不用文字描述数字。

### 反向估值（必做）

这是最有说服力的一段，因为它把估值从"贵不贵"变成"能不能实现"。

```
退出所需企业价值 = 本轮投后估值 × 目标 MOIC × (1 + 预期稀释率)
退出时所需收入 = 退出所需企业价值 / 退出时 EV/Revenue 倍数
所需收入 CAGR = (退出时所需收入 / 当期收入)^(1/持有年数) - 1
```

把算出来的 CAGR 与行业增速、可比公司历史增速对比。若所需 CAGR 超过行业增速两倍以上，本轮估值即使用可比公司法看着"合理"，实际也无法通过退出兑现。这一段结论要独立成段，直接给判断。

## 四、估值

### 方法选择

| 方法 | 适用 | 数据要求 | 局限 |
|---|---|---|---|
| 可比公司 EV/Revenue | 有收入、可比公司≥5 家 | 上市公司倍数 | 一级市场流动性折价未体现，需打 20%-35% 折扣 |
| 可比交易 EV/Revenue | 近 24 个月同赛道融资/并购 | 交易金额与标的收入 | 交易数据难获取，条款差异大 |
| PS | 高增长、低利润率 | 收入与市值 | 忽略利润率差异，跨商业模式不可比 |
| PEG | 已盈利且增长可预测 | 净利润增速 | 早期亏损项目不适用，不要硬套 |
| 里程碑折现 | 无收入或收入极小的硬科技 | 里程碑价值与概率 | 概率主观，需给区间不给点值 |

硬套 PEG 是常见错误。项目还在亏损时，PEG 的分母为负，指标无意义。这种情况直接说明"PEG 不适用，原因为净利润为负"，改用 EV/Revenue 与里程碑折现。

### 一级市场调整

上市公司倍数不能直接套用，需两步调整：流动性折价 20%-35%（早期项目取上限），控制权或少数股权调整（少数股权通常再折 10%-20%）。调整过程要写成可复算的式子，不要只给结论数字。

### 估值结论的表达

给区间不给点值，并说明区间宽度由什么决定。例如"在 2026 年收入 8000 万至 9500 万元的假设下，按可比公司 EV/Revenue 中位数 6.2x 并施加 30% 流动性折价，合理投前估值区间为 3.5 亿至 4.1 亿元；区间下沿对应悲观情景，上沿对应收入达标且毛利率维持 52% 以上的情形"。

同时给出：本轮报价对应的隐含倍数、与可比区间的位置（分位数）、以及可接受的最高报价与理由。

## 五、交易结构

### 条款清单

| 条款 | 建议 | 理由与红线 |
|---|---|---|
| 分层投资 | 首笔 60%，余款按 2-3 个里程碑解锁（收入/客户数/技术指标） | 降低一次性定价风险。里程碑须客观可验证，不接受"完成产品优化"这类表述 |
| 优先清算权 | 1x 非参与型，或 1x 参与型但设 2-3x 上限 | 早期项目创始人持股比例高，全额参与型清算会严重削弱激励 |
| 反稀释 | 加权平均（broad-based） | 完全棘轮对创始人惩罚过重，会阻碍后续融资，反而损害投资人利益 |
| 回购 | 触发条件限定为实质性违约、控制权变更、约定期限未上市；单利 6%-8%；义务人为公司+创始人（有限额） | 回购条款的实际价值取决于义务人偿付能力，需评估个人资产状况 |
| 业绩对赌 | 优先股权补偿，现金补偿为辅 | 现金补偿会直接抽走经营资金，与投资目的冲突 |
| 董事会 | 5 席中占 1 席，观察员权 | 早期阶段不必追求席位多数，信息权比投票权更实用 |
| 一票否决 | 限于增减资、章程修改、重大资产处置、关联交易、主营变更 | 负面清单过宽会导致决策僵局，反而拖累公司 |
| 领售与共售 | 领售权设门槛（估值下限+多数同意），共售权全覆盖 | 防止老股东套现离场而新投资人被套 |
| 信息权 | 月度管理报表（15 日内）、季度经营分析、年度审计报告 | 明确交付时间与格式，写进协议而非口头约定 |

### 分层定价

若项目处于估值分歧较大的阶段，可用可转债或 SAFE 结构延后定价，设折扣率与估值上限。代价是结构复杂、创始人接受度低，仅在双方对估值认知差距超过 30% 时使用。

## 六、退出路径

四条路径都要算，不能只讲 IPO。

**IPO**：判断板块适配性。科创板看科创属性与研发投入占比，创业板看成长性与行业负面清单，北交所看规模与规范性，港股 18C 看特专科技认定。关于科创板第五套上市标准（未盈利企业），其适用范围与具体条件随监管政策调整，本报告不对此作确定性判断，实际适用性须由保荐机构依据上交所现行《科创板股票发行上市审核规则》及最新审核动态逐项核对，并在报告"需人工复核事项"中列明。测算时给出对应板块的可比公司中位 PS、所需收入规模、预计时间表。

**并购**：列潜在买家清单，分三类。产业方（现有客户中的龙头、上游器件供应商、同赛道上市公司）、财务方（同赛道 PE、地方产业基金）、跨界方（有场景但无技术的平台公司）。每家说明收购动机与大致支付能力。并购退出的估值通常低于 IPO，按可比交易的 EV/Revenue 中位数下浮 20%-30% 测算。

**老股转让**：后续轮次中部分退出，适用于项目发展良好但 IPO 周期过长的情形。需在协议中保留转让权与优先购买权安排。

**回购**：作为兜底而非主路径。测算时按义务人可偿付上限打折，多数早期项目的回购条款实际可执行比例不足 30%，不要把它当作安全垫计入回报模型。

## 七、投后监控

指标要少而硬，每项设阈值与触发动作。

| 类别 | 指标 | 频率 | 预警阈值 | 触发动作 |
|---|---|---|---|---|
| 财务 | 月度收入、毛利率、经营现金流、现金余额 | 月 | 收入低于预算 20%、runway<9 个月 | 启动董事会专项讨论、冻结新增编制 |
| 业务 | 新增订单、客户数、CR5 占比、复购率 | 月/季 | 订单连续两季下滑、CR1>40% | 要求客户结构改善计划 |
| 技术 | 里程碑达成率、良率、专利授权数 | 季 | 关键里程碑延期>3 个月 | 评估技术路线是否需要调整 |
| 市场 | 份额、竞品价格、招投标中标率 | 季 | 份额连续两季下降、竞品降价>15% | 复核定价与成本结构 |
| 估值 | 下一轮隐含倍数、可比公司倍数变动 | 半年 | 下一轮估值低于本轮 | 评估减值与退出预案 |

派驻安排：早期项目以观察员+季度现场走访为主；持股超过 10% 或单笔金额超过 3000 万元时争取董事席位，并明确进入审计或薪酬委员会。

对赌指标建议不超过三条，且必须是项目最需要被验证的假设。常见组合：累计收入（验证商业化）、核心客户数（验证需求真实性）、毛利率（验证成本控制）。把技术指标写进对赌通常不合适，因为技术达成与商业成功之间没有线性关系。
